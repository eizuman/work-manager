# Work Manager

Статическое адаптивное веб-приложение для учёта работ по объектам. Реализованы календарь работ и планов, финансы, задачи, исполнители, теги, закупки, статистика, несколько объектов и резервные копии. Предметные данные хранятся в Google Sheets; браузер обращается к Google API напрямую.

Проект не имеет backend, сборщика и обязательной установки зависимостей.

## Быстрый запуск

Запустите статический HTTP-сервер из корня репозитория, например:

```powershell
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Origin локального сервера должен быть разрешён в настройках используемого Google OAuth Client ID. Полная настройка описана в [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

## Хранение данных

Новый объект создаётся с листами:

```text
work_log, finance, tasks, tags, purchases, workers, settings
```

Существующая таблица может быть подключена по Sheet ID, но приложение не выполняет полную предварительную проверку её схемы. Перед подключением сверяйтесь с [docs/DATA_MODEL.md](docs/DATA_MODEL.md).
